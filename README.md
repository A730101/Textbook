# 📚 提示詞筆記本管理器

一個簡單易用的網頁應用程式，用於管理和組織你的 AI 提示詞、角色設定、圖像生成提示等。

## ✨ 功能特色

- 📁 **分類管理** - 創建自訂分類來組織你的提示詞
- 📝 **提示詞儲存** - 儲存各種類型的提示詞（角色、圖像、系統提示詞等）
- ✏️ **編輯和註解** - 為每個提示詞添加註解和使用說明
- 📋 **一鍵複製** - 快速複製提示詞到剪貼簿
- 🔍 **搜尋和篩選** - 透過關鍵字快速找到需要的提示詞
- 🏷️ **標籤系統** - 使用標籤來進一步分類和組織
- 💾 **本地儲存** - 所有資料都儲存在瀏覽器本地，無需伺服器
- 📱 **響應式設計** - 支援桌面和行動裝置

## 🚀 快速開始

### 方法 1：直接開啟（最簡單）

1. 下載或 clone 此專案
2. 找到專案資料夾中的 `index.html` 檔案
3. 雙擊開啟，或右鍵選擇用瀏覽器開啟

就是這麼簡單！不需要安裝任何依賴。

### 方法 2：使用本地伺服器（推薦）

如果直接開啟有問題，或想要更好的開發體驗，可以啟動本地伺服器：

**使用提供的啟動腳本：**

- **Linux / macOS**:
  ```bash
  ./start-server.sh
  ```

- **Windows**:
  ```bash
  start-server.bat
  ```

然後在瀏覽器中開啟 `http://localhost:8000`

**或手動啟動：**

如果你已安裝 Python：
```bash
# Python 3
python3 -m http.server 8000

# 或 Python 2
python -m SimpleHTTPServer 8000
```

如果你已安裝 Node.js：
```bash
# 安裝 http-server (只需執行一次)
npm install -g http-server

# 啟動伺服器
http-server -p 8000
```

### 方法 3：部署到線上

你可以將此專案部署到免費的託管平台：

- **GitHub Pages**: 上傳到 GitHub 並啟用 GitHub Pages
- **Netlify**: 拖放專案資料夾到 Netlify

### 使用方式

#### 1. 新增分類

- 點擊左側邊欄的「+」按鈕
- 輸入分類名稱和圖示（emoji）
- 點擊「新增」

預設提供以下分類：
- 🎭 角色扮演
- 🎨 圖像生成
- 🎬 影片生成（包含 Sora 2、Gemini Veo 3.1、Grok 範例）
- ⚙️ 系統提示詞
- ✍️ 創意寫作
- 💻 程式開發

#### 2. 新增提示詞

- 點擊右上角的「+ 新增提示詞」按鈕
- 填寫以下資訊：
  - **標題**：提示詞的名稱
  - **分類**：選擇所屬分類
  - **提示詞內容**：實際的提示詞文字
  - **註解 / 備註**：使用說明或注意事項
  - **標籤**：用逗號分隔的標籤
- 點擊「儲存」

#### 3. 管理提示詞

- **瀏覽**：點擊左側分類來篩選提示詞
- **搜尋**：使用頂部搜尋框搜尋標題、內容、註解或標籤
- **複製**：點擊「📋 複製」按鈕將提示詞複製到剪貼簿
- **編輯**：點擊「✏️ 編輯」按鈕修改提示詞
- **刪除**：點擊「🗑️ 刪除」按鈕刪除提示詞

#### 4. 預設影片生成提示詞

系統預設提供三個 AI 影片生成工具的提示詞範例：

- **Sora 2**：適合電影級場景生成，包含詳細的場景、鏡頭、光線描述格式
- **Gemini Veo 3.1**：適合結構化的商業影片製作，提供清晰的格式化指令
- **Grok**：適合快速創意影片生成，使用簡潔直接的描述風格

這些範例可以直接使用或作為模板修改，幫助你快速上手 AI 影片生成。

## 💡 使用技巧

1. **善用分類**：為不同用途的提示詞創建專門的分類，例如「工作用」、「學習用」等
2. **添加詳細註解**：記錄提示詞的最佳使用場景、參數設定等
3. **使用標籤**：用標籤來標記提示詞的特性，如「創意」、「專業」、「簡短」等
4. **定期整理**：刪除不再使用的提示詞，保持清單整潔
5. **備份資料**：定期匯出瀏覽器的 localStorage 資料作為備份

## 🔒 資料儲存

所有資料都儲存在瀏覽器的 localStorage 中：
- 資料僅存在於本機
- 不會上傳到任何伺服器
- 清除瀏覽器資料會一併清除應用程式資料

### 備份資料

如果需要備份資料，可以：

1. 開啟瀏覽器的開發者工具（F12）
2. 進入 Console 標籤
3. 輸入以下指令匯出資料：

```javascript
// 匯出所有資料
console.log(localStorage.getItem('prompts'));
console.log(localStorage.getItem('categories'));
```

4. 複製輸出的 JSON 資料儲存到檔案中

### 還原資料

```javascript
// 還原資料（替換成你備份的 JSON）
localStorage.setItem('prompts', '你的 prompts JSON');
localStorage.setItem('categories', '你的 categories JSON');
// 重新整理頁面
location.reload();
```
